# Workflow diagrams

The Mermaid (`.mmd`) files in this directory are the current workflow sources. They describe the three-notebook path and are copied from the matching files in `docs/`. Run `./docs/diagrams/generate-diagrams.sh` to render the PNGs embedded in the notebooks.

The `.drawio` files are from the earlier synthetic-data/Redis architecture. They are retained as historical editing files and are not used by the current demo or the PNG generation script.
